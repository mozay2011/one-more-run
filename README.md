# One More Run 🎮

**One More Run** is an endless runner game I made using **Google AI Studio**.

The idea is pretty simple — run as far as you can, dodge obstacles, collect coins, use power-ups, and try not to crash.

## What’s in the game?

* Endless running gameplay
* Increasing difficulty
* CALM, RUSH and CHAOS phases
* Coins and power-ups
* Different characters
* Character upgrades
* Missions
* XP system
* Daily rewards

## How it works

You start off at a slower pace, but the longer you survive, the faster and harder the game gets.

The goal is basically to keep going and beat your previous best run.
